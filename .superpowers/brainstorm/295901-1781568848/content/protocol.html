Contrato WebSocket — Protocolo /ws/run

Formato das mensagens entre Frontend ↔ Backend

Mensagens do Protocolo
Direção Tipo Exemplo Quando
FE → BE execute {"type":"execute"} Após WS connect, inicia execução
FE → BE input {"type":"input","data":"5\n"} Usuário digita no terminal
FE → BE stop {"type":"stop"} Usuário clica Stop
BE → FE output {"type":"output","data":"42\n"} stdout do container
BE → FE error {"type":"error","data":"Segmentation fault"} stderr ou erro de runtime
BE → FE exit {"type":"exit","code":0} Programa terminou (exit code)
BE → FE timeout {"type":"timeout"} Timeout de 10s estourou
Backend: State Machine
# /ws/run handler
ws = flask_sock.Sock(app)
on_connect → validate_jwt(token)
on_msg("execute") → spawn_container()
on_msg("input") → write_stdin(data)
on_msg("stop") → SIGTERM → 1s → SIGKILL
container_thread:
loop: read stdout → ws.send("output")
on_exit → ws.send("exit", code)
timeout_thread:
sleep(10s) → ws.send("timeout") → kill
docker --stop-timeout=2 (safety net)
Frontend: useReducer States
// useExecution.ts
IDLE → ws = null
CONNECTING → new WebSocket(
"ws://host/ws/run?token="+jwt)
RUNNING → ws.send("execute")
terminal focus, botão muda p/ Stop
STOPPING → ws.send("stop")
aguarda msg "exit" ou "timeout"
→ FINISHED (exit code 0)
→ ERROR (exit != 0)
→ TIMEOUT (10s)
