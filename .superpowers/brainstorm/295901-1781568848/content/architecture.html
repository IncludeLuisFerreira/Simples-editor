Arquitetura Sprint 3

Fluxo de execução: Frontend → WebSocket → Backend → Docker Container

Fluxo End-to-End
Frontend
→
1. Usuário clica Run
Código já compilado (Sprint 2 ✅) → binário na sessão
WebSocket
→
2. new WebSocket("ws://host/ws/run?token=<jwt>")
flask-sock + gevent, handshake com JWT do Supabase
Backend
→
3. PtyExecutionStrategy.spawn()
Copia binário → tmpdir → docker run --rm --read-only --network=none
Container
→
4. nobody@container: ./programa
stdin/stdout/stderr via docker attach → PTY → WebSocket frames
Terminal
→
5. xterm.js renderiza output em tempo real
Usuário digita → onData → ws.send() → stdin do container
